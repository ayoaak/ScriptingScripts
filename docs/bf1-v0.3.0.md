# 0.3.0：原生动画卡片堆叠

历史版本说明，当前卡片交互已由 [0.4.0](bf1-v0.4.0.md) 替换。

2026-11-07，修正 0.2.0 的装饰背景叠层实现。

## 卡片交互

- 每层为不同玩家的完整原生卡片，用玩家 ID 作为稳定视图 key；最多同时渲染四层，不再使用空白矩形充当玩家卡片。
- 手指拖动时，当前卡片随位移移动，后卡同时改变位置和缩放，形成补位过程。
- 达到距离或速度阈值后，通过 Scripting `withAnimation(Animation.spring(...), "removed", ...)` 完成原生弹簧动画；未达阈值时回弹。
- 等待原生动画完成后再调整玩家顺序。已补位玩家的 key、位置、缩放在换序前后保持一致，避免正文瞬间被替换。
- 动画进行时锁住重复手势和点击，退出页面或收藏列表改变时使未完成回调失效；仅一位收藏时不拦截列表的滚动手势。
- 移除“上一位”和“下一位”按钮，保留计数及取消收藏。切卡不触发查询，点击当前卡片才进入详情。

## 排版

名称、军衔/等级及下方总击杀所在第一列共用右侧内容栏的左边界，并显式设置 leading 对齐。

普通字号下名称由系统 headline 的 17pt 基准放大至 22.1pt，军衔与等级由 caption 的 12pt 基准放大至 15.6pt，均为原来的 1.3 倍。辅助大字体模式另外增大字号并将统计单列排放。

## 验证

31 项自动化测试通过。其中 28 项覆盖数据逻辑、军衔、卡片位移轨迹、前后层真实身份、双向补位连续性和字号比例；3 项用 Scripting 组件桥接替身检查实际 TSX 组件：无上下按钮、每层绑定真实玩家、原生 spring 完成前不提前换序、短手势回弹及退出后忽略回调。

桥接替身不绘制像素，也不模拟 iPhone 实际帧率；TSX 已通过语法和相对导入检查，目标 Scripting 版本完整声明检查、真机渲染、与 List 的手势竞争仍由用户自行验收。

徽章继续从 GitHub 在线加载，不随安装包打包；账号数据和缓存格式不变。

官方 API 依据：[Scripting Animation and Transition](https://scriptingapp.github.io/guide/View%20Modifiers/Animation%20and%20Transition)、[Text View Modifiers](https://scriptingapp.github.io/guide/View%20Modifiers/Text%20View%20Modifiers)。
