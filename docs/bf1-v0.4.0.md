# 0.4.0：散开、浏览、居中后进入

依据用户提供的 [StyleKit Card Stack](https://www.stylekit.top/zh/styles/card-stack) 叠放、旋转、阴影和散开层次，转换成 Scripting 原生触控交互。保留系统语义颜色和已有 Liquid Glass 操作控件。

- 初始将真实玩家卡片按缩放、旋转和错位叠放，露出后排可点击部分。
- 点击非当前卡片只散开卡组，不查询、不直接进入；也可用“展开卡组”入口操作。
- 展开后上下拖动连续浏览，按滑动速度预测松手位置并吸附；最多同时渲染五位真实玩家，50 位收藏均可到达，首尾有边界。
- 点选目标后将同一张稳定 ID 卡片移到卡组中央、转正、恢复正常大小，其他卡片淡出。等待原生 `withAnimation(..., "removed", ...)` 完成后才调用查询与页面跳转，无固定延时猜测。
- 展开、吸附和进入使用 0.4 秒、无弹跳的原生 spring；动画期间锁定重复操作。退出页面、收藏增删时使旧回调失效。
- 当前卡片可直接进入；收起卡组和取消收藏保留，无上下换人按钮。
- 名称、等级字号保持 1.3 倍，和总击杀同一左边界；徽章继续从 GitHub 加载，安装包排除徽章目录。

`npm test` 共 34 项通过：核心严格编译、12 个运行文件语法及相对导入检查；覆盖卡片散开布局、连续滑动边界、50 位可达性、点选居中终态、展开不查询、动画完成前不进入、重复点击锁定、退出及收藏变更后的迟到回调隔离。组件测试使用桥接替身，不绘制像素，不表示真机动画帧率或触摸行为已验收。

用户自行验收 Scripting 导入、原生动画、List 手势竞争、可读性和设备版本兼容性，见 [验收清单](bf1-validation.md)。
