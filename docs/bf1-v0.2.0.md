# 0.2.0：首页与常用玩家调整

> 历史版本记录。此版本的装饰叠层及上下按钮已由 [0.3.0 原生动画卡片堆叠](bf1-v0.3.0.md) 替换。

2026-11-07，按用户验收反馈修改：

1. 插件显示名与查询页标题改为“战地战绩查询”，保留 Battlefield1Stats 发布目录和原存储键。
2. 图标图像根据用户指定 BF6 图进行编辑，去掉数字 6 区域，保留 BF 与准星元素；同时用于首页标识。素材与来源见 assets/README.md。
3. 查询按钮改为原生 regular 大小，标签固定内容宽度并居中，取消原有放大样式与图标对文字位置的影响；点击区保持至少 44pt 高。
4. 常用玩家改为堆叠卡片。上下滑动环绕切换已收藏玩家，卡片内显示玩家 ID、军衔与等级、总击杀、KD、KPM、胜率和获取时间；点击进入当前卡片玩家详情。切卡不查询远端，也不修改正在查看的详情账号。
5. 0–150 级徽章严格按用户提供的维基页面分组，17 种原始图片放在 GitHub 仓库；安装包排除整个军衔素材目录。运行时从 GitHub raw 地址加载，失败时使用等级占位。
6. 增加上一位/下一位按钮作为手势替代；移除收藏后当前卡片索引自动回到有效位置；零个收藏和只有一位收藏时单独处理。

测试：24 项核心测试通过，包括全部等级对应范围、等级边界、竖向手势阈值、横向误操作和首尾环绕。TS/TSX 语法与相对导入检查通过。徽章签名检查为 PNG，安装包逐文件校验包含新图标而不包含任何徽章 PNG。

真实 iPhone 手势与 List 的竞争、玻璃材质、字号和导入覆盖流程仍由用户自行验收，本次没有进行设备侧操作。0.1.0 的功能及真实接口验证记录保留在既有文档中。
